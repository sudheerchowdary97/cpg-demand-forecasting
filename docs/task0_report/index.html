Hybrid options
Segmented globals (Beverages vs Snacks, or by channel) · geography fine-tuning / adapters · hierarchical reconciliation.
A global model is NOT assumed to beat local — how much to pool is proven by market-level rolling-origin WRMSSE backtests.
Data residency: cross-border pooling is allowed here (public M5 proxy). In a real PepsiCo deployment, raw data may need to stay in-region → region-segmented globals, local fine-tuning, or federated learning.

Tech stack & Mac-local feasibility

Because the data is synthetic (small), the whole stack runs local-first on the Mac — including deep learning via PyTorch MPS. Cloud is optional (scale / real deploy). Only Azure is cloud-only; MATLAB is skipped (licensed).
